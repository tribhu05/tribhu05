# 🚀 Featured Projects

## 🌱 CropGuard — Multi-Crop Disease Detection

> **Deep Learning • Computer Vision • Explainable AI**

One of my main AI/ML projects — an end-to-end plant disease detection system designed to identify diseases across multiple crops.

**What I built:**

* 🧠 Fine-tuned **ConvNeXt-Tiny** using transfer learning
* 🌾 Classified **38 disease classes** across 5+ crop species
* 📈 Achieved **98% test accuracy**
* 🔥 Added **Grad-CAM** to explain model predictions
* 🖼️ Built image preprocessing with OpenCV
* 🌐 Created a Streamlit web application
* ⚡ Prediction response in under 3 seconds
* 👥 Worked as part of a **6-member team**

**Stack**

`Python` `PyTorch` `ConvNeXt` `Grad-CAM` `OpenCV` `Streamlit`

## 🧠 Brain Tumor Detection

> **CNN • Medical Image Classification • Flask**

A computer vision project focused on detecting and classifying brain tumors from MRI images.

**Highlights:**

* 🧠 Transfer learning with **VGG16**
* 📊 ~**95% accuracy**
* 🔄 Image augmentation & preprocessing
* ⚙️ Adam optimizer with tuned learning rate
* 📋 Evaluated using precision, recall, F1-score & confusion matrix
* 🌐 Built a Flask-based prediction interface
* 📷 Real-time MRI upload and prediction

**Stack**

`Python` `TensorFlow` `Keras` `VGG16` `Flask` `OpenCV`
