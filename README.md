## Mindset

**Curiosity as method.** I treat every unknown as a small experiment — training a model twice, once by the book and once to see what breaks, teaches more than either alone.

**Learning in public loops.** Build, evaluate, deploy, repeat. Every project — from a Streamlit app to a LeetCode streak — is a loop I try to tighten a little each time.

**Craft over cleverness.** A model with 98% accuracy means little if no one can see why it decided what it decided. I'd rather ship something explainable than something merely impressive.
